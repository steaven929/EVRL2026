# RL 优化实验方案 (2026.02.05)

## 问题诊断总结

### 核心问题
1. **充电策略缺失**: RL 完全不充电（0次 vs 最优解112次）
2. **服务率低**: RL 仅达到最优解的 45.8%（27次 vs 59次）
3. **动作输出问题**: 充电倾向值极小（< 0.15），无法触发充电
4. **性能差距**: RL reward -3150 vs 最优解 +469.8

### 根本原因
- **Reward 函数**: 固定惩罚 -500 掩盖充电奖励
- **状态空间**: 缺少车辆 SOC 信息
- **充电逻辑**: 触发阈值可能过高

---

## 实验方案设计

### 实验 1: Baseline 重现（验证环境）
**目标**: 确认当前性能并建立基准

**步骤**:
1. 运行 `python main.py --train_eps 100` 训练 100 轮
2. 运行 `python baseline_comparison.py` 测试性能
3. 记录: Reward、SVC、充电次数、动作标准差

**预期结果**:
- Reward: -3000 ~ -3500
- 充电次数: 0
- 动作标准差: < 0.02

**验证标准**: 与当前结果一致

---

### 实验 2: Reward 函数优化（紧急修复）
**目标**: 让 RL 学会充电

**修改内容**:
1. **移除固定惩罚**: `-500` → `0`
2. **增加充电奖励**: `100 * charging_count` → `500 * charging_count`
3. **增强 SOC 惩罚**: 低电量车辆立即惩罚

**修改文件**: `specific/dclily_elec.py` (line 1099, 1138)

**代码修改**:
```python
# =========2026.2.5修改，优化Reward函数==========
# 原: reward_value = (service_revenue + charging_bonus - soc_penalty) / 10 - 500
# 新: 移除固定惩罚，增加充电奖励权重
charging_bonus = 500 * charging_count  # 原100改为500
fixed_penalty = 0  # 原500改为0
reward_value = (service_revenue + charging_bonus - soc_penalty) / 10 - fixed_penalty
# ======修改结束
```

**训练参数**:
- 训练轮数: 300 轮
- 其他参数: 保持默认

**预期结果**:
- Reward: -1500 ~ -2000（提升 50%+）
- 充电次数: 20+ 次
- 服务率: 提升到 60%+

**验证标准**:
- ✅ 充电次数 > 0
- ✅ Reward 提升 > 30%
- ❌ 如果充电次数仍为 0，进入实验 3

---

### 实验 3: 状态空间增强
**目标**: 让 RL 感知电量信息

**修改内容**:
1. 添加车队平均 SOC 到状态空间
2. 添加低电量车辆数量（SOC < 600）
3. 添加充电桩可用率

**修改文件**: `specific/dclily_elec.py`

**状态空间扩展**:
```python
# =========2026.2.5修改，增强状态空间==========
# 原状态: [OD需求 + 充电桩占用 + 充电桩配置]
# 新增: [平均SOC, 低电量车辆数, 充电桩可用率]

avg_soc = np.mean([self.car[i][1] for i in range(self.CAR_NUM)])
low_soc_count = sum(1 for i in range(self.CAR_NUM) if self.car[i][1] < 600)
charger_available_rate = self._get_charger_available_rate()

# 添加到状态向量
enhanced_state = np.concatenate([
    self.state,  # 原状态
    [avg_soc / BATTERY_CAPACITY],  # 归一化平均SOC
    [low_soc_count / self.CAR_NUM],  # 归一化低电量车辆比例
    [charger_available_rate]  # 充电桩可用率
])
# ======修改结束
```

**训练参数**:
- 训练轮数: 500 轮
- 需要重新初始化网络（状态维度变化）

**预期结果**:
- Reward: -1000 ~ -1500
- 充电次数: 50+ 次
- 服务率: 70%+

**验证标准**:
- ✅ 充电次数 > 实验2
- ✅ Reward 持续改善
- ✅ 动作标准差 > 0.05
